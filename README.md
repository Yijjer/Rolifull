# Roliful

A free, open-source browser extension for Rolimons and Roblox trading. By jjoyful.

## About

Roliful is a trading companion extension designed to make Rolimons and Roblox trading faster, safer, and more informative. All code is transparent, open-source, and safe to use. You can review the code yourself or run it through an AI to verify its safety.

**Join our Discord:** https://discord.gg/NpwDMxdem

## Features

### Trade Presets
Save and load pre-configured trade offers. Quickly set up trades with your favorite item combinations and Robux amounts without manually selecting items every time.
- Save up to 4 items per side plus custom Robux amounts
- Load presets with one click
- Optional auto-send (disabled by default for safety)

### Player Information Cards
View player details directly on Rolimons trade listings:
- Recent Average Price (RAP) and player value
- Rolimons badges and status
- Quick inventory preview of top items and hoarded collectibles
- "New Trader" highlighting for players without trade history

### Trade Eligibility Checker
Instantly see if a player can receive trades. Disabled trade buttons show why a player isn't eligible.

### Player Profile Enrichment
Enhanced player profiles on Rolimons showing:
- Display name
- Social stats (friends, followers, following)
- Account age and group memberships
- Roblox bio/description

### Deals Page Filtering
Filter out "dynamic face" bundles from the Rolimons deals page to find the trades you're looking for faster.

### Item Page Toolbar
Quick-access toolbar for Rolimons item pages (extensible for future features).

## Installation

1. Clone or download this repository
2. Open `chrome://extensions/` in Chrome/Edge
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" and select the `tradeext` folder
5. Refresh Rolimons and Roblox trading pages

## Usage

### Trade Presets
- Navigate to the Roblox trade page
- Configure your desired items and Robux amount
- Click the Roliful preset panel to save your current setup
- Later, load the saved preset and confirm or auto-send

### Player Lookup
- Visit any Rolimons trade listing or player profile
- Roliful automatically enriches pages with player value and trade info
- Hover over player cards to see inventory previews

## Safety & Transparency

✅ **No credential theft** — Never stores or transmits your username, password, or login tokens  
✅ **No data exfiltration** — All data stays on your computer or goes to official Roblox/Rolimons APIs  
✅ **No obfuscation** — Code is readable and unminified. Review it anytime.  
✅ **Limited permissions** — Only accesses Roblox and Rolimons domains  
✅ **No tracking** — No analytics, telemetry, or third-party data collection  

**Auto-Send Disclaimer:** The trade auto-send feature is optional and disabled by default. If you enable it, trades will send automatically after loading a preset. Always review trades before enabling auto-send.
