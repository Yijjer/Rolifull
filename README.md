# Roliful

A free, open-source browser extension for Rolimons and Roblox trading. By jjoyful.

## About

Roliful is a trading companion extension designed to make Rolimons and Roblox trading faster, safer, and more informative. All code is transparent, open-source, and safe to use. You can review the code yourself or run it through an AI to verify its safety.

**Join our Discord:** https://discord.gg/NpwDMxdem

## Features

### Trade Ads
Infoboxes - Gives you an overall gist on the user's trading position
New trader highlights - Highlights traders with low trade ads (+ a filter option)
Inventory Preview - Preview the user's inventory without swapping pages

### Profiles
Trade Eligibility Checker - Gives you a warning before attempting to trade with the user
Profile Stats - Gives various information such as: friends/following/group counts, account age, RoPro tier
Relationship Status - Shows if the user is interacting with your profile via roblox interactions (following, friends, follower)
Description Box (soon depreciated due to roblox remove this information from their api)
Wishlist shortcut
Rare Serial Highlights - Adds a little star on top of any rare serials on item cards in the trader's profile

### Deals Page
Hide Dynamic Faces - Removes all dynamic faces deals to see non-face deals
Show Serials - Shows serials of deals incase one is a rare serial. (+ A serial items only filter for potential serial sniping)
